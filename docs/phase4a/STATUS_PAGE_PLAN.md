# Status Page Plan

## Minimum public components
- API availability
- Sync/collaboration availability
- AI generation availability
- Background jobs / automations availability

## Update rules
- Create an incident entry for any `SEV-1` or `SEV-2`.
- Update within 15 minutes of confirmation.
- Post resolution summary after service is stable.

## Owner
- Product operations owns wording.
- Engineering owns technical state and remediation ETA.
