專案目標

本季度目標是將 Pegn-AI 打造成可以媲美 Notion 的 AI 原生工作系統，結合知識圖譜與多智能體協作，讓知識工作者效率提升 3 倍。核心差異化點在於 AI 深度整合——不只是「加上 AI 的 Notion」，而是「以 AI 為核心的工作 OS」。

本文件包含機密設計決策，請勿在工作區外分享。所有設計規格以本頁面為準，更新後自動同步至 設計系統。

技術架構

後端採用 Node.js + Express，資料庫使用 PostgreSQL 15+（含 pgvector 向量搜尋）。前端為 React + Vite + Tailwind CSS + Framer Motion。即時協作透過 WebSocket（ws 套件）實現，LLM 透過 LLMProvider 抽象層整合多種模型後端。

LLM 抽象層範例

interface LLMProvider {
  name: string;
  generate(prompt: string, input: string): Promise<string>;
}

class GeminiLLMProvider implements LLMProvider {
  name = 'gemini-1.5-pro';
  async generate(prompt: string, input: string) {
    // 呼叫 Google Generative AI SDK
    const result = await model.generateContent([prompt, input]);
    return result.response.text();
  }
}
⚠️
注意：pgvector extension 需要 PostgreSQL 15+，並需執行 CREATE EXTENSION vector;。部署前請確認版本兼容性。

設計原則

「少即是多——每一個視覺元素都應有其存在的理由。最好的設計是讓用戶忘記它的存在，只感受到順暢。」
  • 內容優先：UI 退到背景，讓文字與思想佔據舞台
  • 進階揭示：控制項只在需要時出現（hover/focus）
  • 一致的動感：所有動畫使用相同的 spring easing
  • 無障礙設計：確保鍵盤可操作，色彩對比達 WCAG AA
